Quill is an unofficial Telegram client and still in beta.

### Security

- Message widgets are now off by default, on new installs and on upgrades (#1486). A widget is a program written by whoever runs the bot, so a flaw in its sandbox could give that person a way into Quill and your computer. A widget message now shows a "Widgets are off" notice with a Turn On Widgets… button. Turning them on first shows a warning about what a malicious widget could do, and it only goes ahead once you tick the box saying you understand. You can switch widgets off again at any time in Settings › Privacy and Security, which stops every running widget at once.

### Reliability

- A new check stops interface text from being added as a Quill-only phrase when Telegram already has the same English phrase, so more of the interface gets Telegram's own translations (#1481, from #1478 by `@sprainbrains`).
- Quill's tests were cleaned up: tests that checked nothing were removed and tests that waited on the clock now run on simulated time, so test runs are faster and no longer fail at random (#1482, #1483, #1485).

### Not yet tested on a live account

- The widget warning was checked with tests and offline demos, not on a live account.
